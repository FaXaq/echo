# OrganizationScope has two trusted constructors, not one

`OrganizationScope` (see ADR-0002) is a branded type infrastructure functions require instead of a raw `organizationId`, constructed only by trusted code. One caller doesn't fit the request path: better-auth's `beforeDeleteOrganization` hook calls `deleteOrganizationFiles` → `listFilesByOrganization` entirely outside tRPC, with no request/caller to membership-check against. Rather than carve out an exception where that one function accepts a raw string — which would reopen the "structurally impossible to call unscoped" guarantee the type exists to provide — we ship a second, explicitly named constructor for trusted non-request code paths (lifecycle hooks, future cron/migration jobs), alongside the request-scoped one used by the organization-scoped tRPC procedure. Both constructors live next to the `OrganizationScope` type itself; nothing else may construct one.
